# 04_keyframes-assets / 关键帧与素材资产（用户生成后手动放，永久保留）

> 本目录存放用户生成的图像/音频类资产：
> - 关键帧（每段首帧+尾帧，共 N 段 × 2 张）
> - 可选：TTS 配音成品音频
> - 可选：角色参考图 / 场景参考图

## 子目录建议：
| 子目录 | 内容 | 命名规范（严格遵守 naming-rules.yaml）|
|---|---|---|
| `keyframes/9x16-version/original/` | 9x16 每段首/尾帧原始 PNG | `kf-shot-<ID>-<head/tail>-<SEMANTIC>-v01.png` |
| `tts-audio/` | TTS 配音成品 | `tts-shot-<ID>-<ROLE>-v01.mp3` |
| `other-assets/` | 其他参考素材 | 符合前缀规范 |
