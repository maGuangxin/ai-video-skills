# 99_temporary-workspace / 临时工作区（每阶段生成删除建议，需用户手动确认删除，Skill 不会自动删除任何文件）

> 存放「草稿 / 拆分镜缓存 / 提示词实验版 / 每阶段不合格清单缓存 / 旧作废归档

## 固定子目录：
| 子目录 | 内容 | 什么时候建议删除 |
|---|---|---|
| `draft-versions/` | 实验版提示词 / 临时改稿（不影响主线提示词） | 该阶段完成后 24h |
| `storyboard-split-cache/` | 拆分镜中间缓存文件 | 分镜确认锁定后 |
| `prompt-experimental/` | 提示词实验版 | 最优版本确定后 |
| `archive-old-storyboards/` | 旧 15s 作废分镜 / 旧提示词（永久归档不删） | 永久保留，不建议删 |
| `cleanup-suggestions/` | 每阶段 Skill 自动生成的删除建议清单（列出文件名+原因+建议删除时间）**用户手动确认后再删，Skill 不自动删**防误删 | 看完删掉或归档 |
