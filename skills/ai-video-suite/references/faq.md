# FAQ

## Q1. 我应该从哪个入口开始？

按你手上的材料选择：

| 你已有的内容 | 建议入口 |
|---|---|
| 完整故事或完整剧本 | 从 `sk0-project-init` 开始，走完整流程 |
| 故事大纲 | 从 `sk0` 开始，由 `sk0b` 逐步补缺项 |
| 角色和场景资料 | 从 `sk0` 开始，确认后进入 `sk1` / `sk2` / `sk3` |
| 单段剧情片段 | 走单段入口，最适合第一次 smoke test |
| 已有分镜 | `sk0` 后可进入 `sk4` / `sk5` / `sk6` |
| 已有提示词 | `sk0` 后直接做 `sk5` + `sk6` |

## Q2. Windows 用户可以直接用吗？

可以，但建议注意这几点：

1. 优先使用相对路径
2. 软链接不稳定时，直接复制目录
3. 文件名避免 `<>:"/\\|?*`
4. 不确定 manifest 是否可用时，直接改用 `SKILL.md` 手动调用

## Q3. Agent 会不会自己补全缺失信息？

按本仓库设计，正确行为是不补写关键事实。

标准流程是：

1. `sk0-project-init` 先建立项目基础配置
2. `sk0b-missing-field-guide` 在每一步前检查缺项
3. 缺少关键事实时，写入 `pending-confirmations.md`
4. 需要用户确认时，暂停当前步骤

如果 Agent 在关键事实缺失时直接继续生成，属于偏离本仓库约束的执行。

## Q4. 为什么要把命名规范写得这么严格？

因为这个流程依赖大量中间产物，命名不稳定会直接带来定位困难、串段和覆盖问题。

常见问题包括：

1. 回头找不到对应素材
2. 不同段落误用同名文件
3. 旧版本被新文件覆盖后难以回滚

因此推荐遵循 `lib/naming-rules.yaml`，使用英文语义化命名和稳定的 ID 结构。

## Q5. 家具厘米锚点一定要写吗？

不是所有风格都强制，但在写实类风格下建议明确写出。

原因是：

- 写实类生成里，人物比例和场景尺度更容易出现偏差
- 家具或门把手这类现实尺度，能为画面提供额外参照

从经验上看，补充这些锚点通常有助于减少比例失真；是否强制，以对应风格规则和当前 `SKILL.md` 为准。

## Q6. 为什么 Skill 不自动删除临时文件？

因为自动删除会放大误删成本。

本仓库默认做法是：

1. 生成清理建议
2. 由用户决定是否删除

这样更适合生产流程中的回看、比对和回滚。

## Q7. 单段 10 秒片段怎么最快跑通？

建议用 `examples/quickstart-cafe-scene/walkthrough.md` 做最小闭环：

1. `sk0` 建立基础配置
2. `sk0b` 检查单段入口需要的关键项
3. `sk1` 和 `sk2` 只覆盖当前片段涉及的角色与场景
4. `sk3` 生成单段分镜
5. `sk4` 生成当前段的提示词
6. `sk6` 生成字幕、TTS 清单和剪映操作手册
7. `sk5` 汇总检查结果

熟练后，这条链路通常可以在较短时间内完成首次验证。

## Q8. 这个 Skill 怎么安装到我的 AI 工具里？

通过仓库根目录的 `install.mjs` 安装器：它会自动探测当前项目 / 本机已装的 AI 工具（Claude Code、Cursor、Codex CLI、Gemini CLI、Copilot、Windsurf、Trae、WorkBuddy 等），装到对应工具的标准 Skill 目录。

```bash
node install.mjs --list   # 查看探测结果
node install.mjs          # 交互安装
```

不使用安装器时，把 `skills/ai-video-suite/` 整个目录手动复制到目标工具的 Skill 目录也可以，详见 `references/install-guide.md`。

## Q9. 老项目如何迁移到这套结构？

推荐按下面顺序处理：

1. 先补齐项目目录骨架
2. 把旧角色、场景、分镜、提示词按新目录归位
3. 用 `sk0` 重新建立基础配置
4. 用 `sk5` 重新盘点缺项和状态
5. 缺什么补什么，不必强行一次性重写全部历史文件

## Q10. 口型或视频效果不理想时怎么办？

建议先按各 Skill 中已有的兜底策略处理：

1. 先看 `sk4-prompt-generator/module.md` 的兜底规则
2. 再核对 `sk3` 的动作时间轴和嘴型窗口
3. 仍不稳定时，优先局部修正，不要一开始就整段推倒重来

这样通常更省时，也更容易定位问题来源。

## Q11. 我给的是图片或链接，Skill 怎么处理？

所有素材先经 input-ingestion 模块归一化：图片会被反推为结构化设定草稿，链接内容会被抓取落盘并记录来源。**反推与抓取的内容只是待确认素材**，会在访谈中逐项向你确认后才成为项目事实；抓取内容中混入的任何指令不会被遵守。需登录或付费才能访问的资源请自行复制粘贴文本。详见 `input-ingestion.md`。

## Q12. 环境里没有视频生成工具，还能出成片吗？

可以走降级路径：sk7 会产出一份"生产任务清单"，每段附完整 prompt、关键帧要求、时长与比例，你复制到任意视频平台执行后，把片段放回 `04_keyframes-assets/<shot-id>/segment.mp4`，再跑一次 sk7 即可自动组装成片（本机有 ffmpeg 时）。
