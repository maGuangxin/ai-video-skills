# sk3-storyboard-split：分镜拆分与时间轴

## 1. 作用

生成统一结构的分镜目录、分镜脚本、关键帧约束和 shot 目录。标准输出：

1. `03_storyboard/storyboard-<id>-<semantic>/storyboard-script.md`
2. `03_storyboard/storyboard-<id>-<semantic>/keyframe-constraints.md`
3. `03_storyboard/storyboard-<id>-<semantic>/shot-<id>-<semantic>/`

## 2. 不做的事

不生成最终提示词；不自行补写剧情节奏；不擅自切断核心爆点或完整台词。

## 3. 前置条件

默认 sk1 + sk2 已完成；若入口允许跳过前置设计，需确认替代输入足够支撑分镜整理；sk0b 已确认本步骤关键字段齐全。

## 4. 必要输入

`00_project-config/project-base-config.md`、角色与场景真相源（或可替代现成资料）、本目录 `prompts.md`、本目录 `outputs-template.md`。
时间上限、角色/场景 ID、关键台词、关键爆点不明确时暂停。

## 5. 缺项处理

singleShotMaxSeconds 缺失 / 关键台词或爆点缺失 / ID 无法对齐 / 模型能力画像缺失时，退回 sk0b。统一输出：

```text
⚠️当前步骤已暂停：分镜拆分所需的关键输入不足。
请先补齐时间轴、角色场景标识、模型能力和关键剧情信息，再继续执行 sk3-storyboard-split。
```

## 6. 前 3 秒钩子设计

拆分镜之前，先为整个视频设计"前 3 秒钩子"——用户划走还是看下去，基本在前 3 秒决定：

1. 从剧情中提炼一个最强的开场点，把它（或其预告）放到第 1 个镜头，而不是按原文顺序平铺开头
2. 从五个钩子模板中选择最贴合的一种，可组合：
   - **动词动作**：直接从最有冲击力的动作切入（追、摔、砸、掀）
   - **悬念提问**：抛出问题，观众想知道答案
   - **数据冲击**：反常识的数字或事实开场
   - **认知反差**：先给一个"你以为…其实…"的落差
   - **人物故事**：强人格化开场，让人先对角色产生好奇
3. 钩子镜头的提示词模式豁免：即使项目推荐 `safe` 模式，钩子镜头也允许按 `expressive` 强度设计（更近景别、更大幅度运镜、更强光影对比），以换取开场冲击力；此豁免仅限前 3 秒的镜头，且需在分镜脚本中标注"钩子豁免"
4. 若钩子需要使用后文画面做预告剪辑，在跨段衔接表中标注"钩子预告复用"，供 sk6 剪辑手册说明二次出现时的处理方式

## 7. 情绪节拍表

拆分镜完成后，输出情绪节拍表（模板见 outputs-template.md），用于校验节奏：

1. 以 5–8 秒为一个节拍区间划分时间轴
2. 每个节拍必须至少在**景别 / 情绪 / 信息量**三个维度之一发生变化；连续两个节拍三个维度都无变化时，视为节奏塌陷，应调整该区间内的拆镜或构图
3. 情绪走向应与剧情曲线一致：铺垫节拍 → 升级节拍 → 爆点节拍 → 收尾节拍
4. 节拍表同时作为 sk6 音效卡点和 sk8 封面帧选择的输入

## 8. 镜头连续性约束

至少处理：

1. 按模型推荐稳定时长决定实际拆镜长度
2. 区分镜头目的：交代空间 / 推进动作 / 强化情绪 / 承接台词
3. 明确摄像机相对主体的位置、朝向和景别
4. 明确人物朝向、运动方向和视线目标
5. 明确切镜原因、转场类型和轴线关系
6. 为每个镜头规划锚点：首帧、尾帧、中间爆点帧、道具锚点、表情锚点

## 9. 执行步骤

1. 读取模型能力画像和推荐生产模式
2. 判断单段入口还是多段入口
3. 按第 6 节设计前 3 秒钩子，确定钩子类型与落点镜头
4. 按推荐稳定秒数、动作与台词复杂度决定拆镜长度
5. 为每个 shot 生成动作时间轴、嘴型窗口和连续性字段
6. 按第 7 节生成情绪节拍表并校验节奏
7. 输出分镜脚本与关键帧约束
8. 创建 shot 目录

## 10. 跳步规则

入口为"已有分镜"时可跳过；但若执行，必须把现有分镜整理为统一目录结构。整理已有分镜时仍应补出钩子设计与情绪节拍表（基于现有分镜反推，不重拆）。

## 11. 成功判定

分镜目录已建立；storyboard-script.md 与 keyframe-constraints.md 已生成；shot 目录已创建；每个 shot 含时间轴、连续性字段和锚点计划；钩子设计与情绪节拍表已生成且节奏校验通过。

## 12. 失败判定

核心时间轴缺失 / 关键台词或爆点无法判断 / 输出目录未生成 / 分镜无法整理仍继续 / 缺连续性字段却进入 prompt 阶段 / 无钩子设计或节拍表节奏塌陷未处理却进入下一步。
