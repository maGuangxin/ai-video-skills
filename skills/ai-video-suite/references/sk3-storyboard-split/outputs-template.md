## F. 情绪节拍表
> 以 5–8 秒为一个节拍区间；每个节拍必须在 景别 / 情绪 / 信息量 至少一个维度发生变化。

| 节拍 | 时间区间 | 对应 shot | 情绪 | 信息量变化 | 景别或视觉变化 | 节拍角色 |
|---|---|---|---|---|---|---|
| 1 | `00:00–00:06` | | `<紧张/好奇/压抑…>` | | | `<铺垫 / 升级 / 爆点 / 收尾>` |
| 2 | `00:06–00:12` | | | | | |

### 节奏校验
- 是否存在连续两个节拍三个维度均无变化（节奏塌陷）：`<无 / 有，已调整：说明>`
- 爆点节拍是否与核心爆点清单对齐：`<是 / 否，原因>`
- 本表同时作为 sk6 音效卡点与 sk8 封面帧选择的输入
