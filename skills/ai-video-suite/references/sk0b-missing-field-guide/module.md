# sk0b-missing-field-guide：缺项预检

## 1. 作用

全局 pre-hook：执行 sk1–sk6 前检查关键输入是否缺失。职责是暂停并指出缺什么，不是继续执行。

## 2. 不做的事

不补写默认值；不替用户猜测事实；不在关键字段缺失时放行后续模块。

## 3. 前置条件

- `sk0-project-init` 已生成 project-base-config.md
- 当前目标模块已知

目标模块未知或配置文件不存在时立即暂停。

## 4. 必要输入

- `00_project-config/project-base-config.md`
- 目标模块对应的 Schema 或其"必要输入"章节
- 本目录 `prompts.md`

## 5. 缺项判定

字段缺失 / 空字符串 / null / `⚠️待用户确认` / 含义不明确，统一视为未完成。

## 6. 执行步骤

1. 确认当前目标模块
2. 读取该模块的 Schema 或必要输入清单
3. 对照 project-base-config.md 检查关键字段
4. 缺项时更新 pending-confirmations.md
5. 必要时生成本轮缺项清单到 `99_temporary-workspace/`
6. 返回"允许启动"或"暂停启动"的明确结论

## 7. 固定输出话术

通过：`✅缺项校验通过，可以启动当前目标模块。`
未通过：`⚠️当前步骤已暂停：仍有关键缺项未确认。请先补齐 pending-confirmations.md 中的内容，再继续执行当前目标模块。`

## 8. 跳步规则

本模块不作为内容产出步骤被跳过；进入 sk1–sk8 前都应先执行。

## 9. 成功判定

已明确给出是否允许启动；新缺项已写入记录文件；未在关键缺项存在时继续执行。

## 10. 失败判定

配置文件不存在 / 目标模块未知 / 发现缺项未记录 / 缺项未确认却放行。
