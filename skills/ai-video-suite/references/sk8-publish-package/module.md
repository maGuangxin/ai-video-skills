# sk8-publish-package：发布包

## 1. 作用

成片就绪后，生成面向发布平台的发布包，并承接发布后的数据回流：

1. `05_final-deliverables/publish/publish-package.md`（封面帧、标题、话题标签、发布建议）
2. `05_final-deliverables/publish/performance-review.md`（发布后数据回流，用户手动触发）

## 2. 不做的事

- 不代用户执行任何发布、上传或平台操作
- 不自动读取平台后台数据；性能数据由用户提供后整理回流
- 不在数据缺失时虚构完播率、点赞数等指标
- 不生成违反平台规范的标题党或诱导性文案建议

## 3. 前置条件

sk7 已产出成片或组装清单；sk3 的情绪节拍表与钩子设计可读（作为封面帧与标题的输入）。无成片但有完整分镜与关键帧时，可提前生成发布包草稿并标注"成片未定稿，封面与标题可能调整"。

## 4. 必要输入

`05_final-deliverables/`（成片或组装清单）、`03_storyboard/**/storyboard-script.md`（钩子设计与情绪节拍表）、`00_project-config/project-base-config.md`（发布平台、总时长）。发布平台或成片缺失时暂停。

## 5. 缺项处理

发布平台 / 成片 / 钩子设计缺失时暂停。统一输出：

```text
⚠️当前步骤已暂停：发布包生成所需的发布平台或成片信息不完整。
请先确认发布平台并完成成片（或明确按草稿模式生成），再继续执行 sk8-publish-package。
```

## 6. 发布包内容

按发布平台（sk0 配置）适配，至少包含：

1. **封面帧建议**：从情绪节拍表的爆点节拍与钩子镜头中选 2–3 个候选帧，说明每帧的选择理由与文字叠加建议；竖屏封面注意平台安全区
2. **标题文案**：3 个候选标题，风格贴合平台（抖音口语化强钩子 / 小红书面向搜索的关键词式 / B 站信息量优先）；长度按平台限制校验
3. **话题标签**：3–6 个，组合"大流量标签 + 精准垂类标签 + 内容特征标签"，不做堆砌
4. **发布建议**：发布时段参考、首条评论引导语建议、是否建议置顶评论补充信息

## 7. 数据回流

用户发布后手动提供平台数据（完播率、平均播放时长、点赞、评论、转发、涨粉等）时：

1. 整理写入 `performance-review.md`，标注数据来源与统计时间窗口
2. 对照发布前的预期（总时长档位、钩子类型、节拍结构）给出复盘：哪个节拍可能流失观众、标题与封面是否匹配内容
3. 回流结论只写入本项目文档，供下一个项目参考，不修改已发布的成片
4. 数据不足时明确标注"样本不足，结论仅供参考"，不输出确定性归因

## 8. 执行步骤

1. 读取发布平台配置、成片位置、钩子设计与情绪节拍表
2. 生成封面帧候选与选择理由
3. 按平台风格生成 3 个候选标题与话题标签
4. 生成发布建议
5. 用户发布并回传数据后，按第 7 节生成 performance-review.md

## 9. 跳步规则

可选模块。用户明确表示"只要成片，不做发布包"时跳过；跳过不影响其他模块。已有成片的入口（入口 7）也可直接进入本模块生成发布包。

## 10. 成功判定

publish-package.md 已生成，包含封面帧候选、候选标题、话题标签与发布建议；封面帧与标题均能追溯到钩子设计或情绪节拍表的依据。

## 11. 失败判定

发布平台缺失仍生成 / 标题风格与平台明显不匹配 / 封面帧无选择理由 / 数据回流中出现虚构指标 / 平台数据未确认却写成结论。
