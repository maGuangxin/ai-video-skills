# 使用说明

## 安装后怎么开始

安装成功后，在对应 AI 工具里直接用自然语言对话即可。入口话术示例：

- "我想做一个 AI 短视频，从哪开始？"
- "把这份剧本做成短视频：<粘贴文本>"
- "用这张角色图和这段剧情，帮我出分镜"

入口会自动路由到 sk0，先建项目配置和模型能力画像，再逐步推进。

## 你可以提供什么（六种输入形式）

| 形式 | 示例 | 说明 |
|---|---|---|
| 对话文本 | 直接粘贴故事、大纲、角色设定 | 最常用，原文会完整归档 |
| 文本文件 | "读一下 ~/story/novel-ch1.md" | 支持 .txt / .md 剧本，.csv / .json 已有分镜 |
| 纯图片 | 上传角色设定图 / 场景参考图 / 风格板 | 会反推为结构化设定草稿，等你确认 |
| 图文结合 | 剧本文件 + 参考图一起给 | 文本与图片分别归档、交叉引用 |
| 互联网资源 | "参考这个链接里的章节：https://..." | 抓取内容落盘并记录来源；需登录的内容请自行复制粘贴 |
| 既有项目 | "继续上次的 XX 项目" | 读取进度总览，从第一个未完成步骤继续 |

所有输入先归档到项目 `99_temporary-workspace/raw-inputs/` 并登记素材清单；**图片反推和网页抓取的内容只是草稿素材，你确认后才会成为项目事实**。

## 端到端流程（你最终会拿到什么）

```
sk0 项目配置与模型画像
  → sk0b 缺项预检（每步之前自动运行）
  → sk1 角色设计 ＋ sk2 场景设计（可并行）
  → sk3 分镜拆分
  → sk4 提示词生成 ──→ sk5 一致性审计
  → sk6 字幕/TTS/音频路线
  → sk7 媒体生产与成片组装
```

项目目录结构（在你的项目根目录生成）：

```
00_project-config/    配置、素材清单、待确认项、进度总览
01_character-design/  角色真相源与一致性规则
02_scene-design/      场景真相源
03_storyboard/        分镜脚本、关键帧约束、每 shot 提示词
04_keyframes-assets/  关键帧图与视频片段
05_final-deliverables/ SRT、TTS 清单、成片、剪辑手册、发布包
99_temporary-workspace/ 原始素材、审计问题、作废产物
```

最终产物：`05_final-deliverables/film/full-film.mp4`（当运行环境具备生成工具与 ffmpeg 时自动组装）；否则得到一份可直接复制到任何视频平台执行的生产任务清单 + 全部提示词与关键帧。

## 中途修改设定怎么办

直接说明要改什么（如"角色换成黑发""改成 16:9"）。Skill 会按运行规则的失效表判断哪些产物需要重做、哪些保留，先给你变更范围确认，再执行。
