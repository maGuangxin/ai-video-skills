# sk6-postproduction-bundle：后期交付包

## 1. 作用

基于分镜时间轴生成后期交付包：

1. `05_final-deliverables/subtitles/sub-shot-<id>.srt`
2. `05_final-deliverables/subtitles/full-film-unified.srt`
3. `05_final-deliverables/tts/tts-voiceover-full.md`
4. `05_final-deliverables/tutorials/jianying-step-by-step.md`
5. `05_final-deliverables/audio/voice-strategy.md`
6. `05_final-deliverables/audio/sound-design.md`

## 2. 不做的事

不调用 TTS 服务实际生成音频；不自动操作剪辑软件；不导出最终视频文件；不代用户挑选或下载版权音乐（只给出选曲方向与卡点说明）。

## 3. 前置条件

sk3 已生成可用时间轴；配置中配音、模型能力和命名相关字段可读。本模块不要求 sk4 先完成。

## 4. 必要输入

`03_storyboard/**/storyboard-script.md`、`00_project-config/project-base-config.md`、本目录 `outputs-template.md`。
情绪节拍表（storyboard-script.md 的 F 节）为音效卡点的输入，缺失时按第 10 节降级处理。
shot ID、台词原文或起止秒缺失时暂停。

## 5. 缺项处理

shot ID / 台词原文 / 起止秒 / 时间轴 / 音频路线缺失时，暂停并退回 sk3。统一输出：

```text
⚠️当前步骤已暂停：后期交付包生成所需的时间轴或音频路由信息不完整。
请先补齐分镜时间轴、台词信息和音频路线，再继续执行 sk6-postproduction-bundle。
```

## 6. 音频路线

1. `mute_plus_tts` 2. `native_audio` 3. `hybrid`

同时输出：为什么采用这条路线 / 哪些镜头适合保留原生音频 / 哪些建议回退 TTS / 剪辑阶段连续性检查建议。

## 7. 短视频字幕风格规则

SRT 是通用字幕格式；但面向抖音 / 视频号 / 快手 / 小红书等竖屏平台发布时，剪辑阶段的字幕呈现应按短视频风格处理（写入剪辑操作手册，由用户在剪辑软件中执行）：

1. **竖屏安全区**：字幕放在画面下方约 10%–22% 高度区间，避开平台 UI（右侧互动按钮栏、底部文案与进度条、顶部导航）；发布平台为 B 站横屏时可放宽
2. **单行长度**：每行不超过 12 个汉字，超长自动断行；SRT 分段时已按此校验
3. **关键词强调**：每条字幕最多高亮 1–2 个关键词（颜色或字号），用于强化钩子与爆点；情绪强度高的台词可用更大字号
4. 字体、颜色等具体样式按项目美术风格决定，在剪辑手册中给出建议值，不写死

## 8. BGM 与音效设计（sound-design.md）

按镜头粒度给出音效建议，依据情绪节拍表（sk3 产物）卡点：

1. **每镜头音效建议**：转场 whoosh / 强调 hit / 环境底噪 / 特殊音效（如玻璃碎裂、心跳），无建议时标"无"
2. **卡点**：节拍切换点优先落在音效重音上；爆点节拍必配强调类音效
3. **BGM 方向**：给出情绪基调（如轻快/紧张/抒情）、参考节奏区间（BPM）、结构建议（哪里进副歌、哪里抽底鼓留白），不指定具体曲目
4. **音量关系**：台词 > 音效 > BGM 的默认混音层级建议，写入剪辑手册
5. 版权提示：提醒用户使用平台曲库或免版权音乐，本模块不提供具体音乐文件

## 9. 执行步骤

1. 读取分镜时间轴、音频路线和情绪节拍表
2. 用 `scripts/gen-srt.py` 从分镜表生成分段 SRT（脚本缺失或失败时人工生成，并在交付时标注"未脚本校验"）
3. 合成全片统一 SRT 并校验时间码单调性
4. 按音频路线生成 TTS 清单、审校说明或混合方案
5. 按第 8 节生成 sound-design.md
6. 生成 voice-strategy.md 和剪辑软件操作手册（含短视频字幕风格规则与安全区建议）

## 10. 跳步规则

sk3 完成后即可执行，不必等待 sk4；项目明确关闭原生台词或口型能力不足时优先静音+TTS 路线。情绪节拍表缺失时，音效卡点建议降级为按镜头边界对齐，并在 sound-design.md 中标注"节拍表缺失，卡点未校验"。

## 11. 成功判定

分段与全片 SRT 已生成（时间码经校验）；TTS 清单已生成或明确标记不启用；voice-strategy.md、sound-design.md 与操作手册已生成；竖屏项目的操作手册包含字幕安全区与短视频字幕风格说明。

## 12. 失败判定

时间轴缺失 / 关键输出未生成 / 字幕或 TTS 内容与分镜台词不一致 / 音频路线与模型能力明显不匹配却未提示回退 / 竖屏项目操作手册缺失安全区说明。
