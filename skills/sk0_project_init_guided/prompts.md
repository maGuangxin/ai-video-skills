# sk0_project_init_guided / prompts.md

> 原则：只用用户容易理解的表达，不先抛专业术语。每次只问一项，等用户回答后再进入下一项。
> 新增要求：如果用户目标包含“在当前项目 IDE 里直接使用 Skill”，必须额外确认项目根目录安装方式与 `.trae` 生效方式。
